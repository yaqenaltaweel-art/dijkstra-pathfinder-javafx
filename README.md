# Dijkstra Pathfinder JavaFX

A JavaFX application that visualizes the shortest path between graph nodes using **Dijkstra's Algorithm**.

The project was developed to apply graph algorithms and custom data structures in a practical graphical application.

## Features

- Find the shortest path between two nodes
- Calculate routes based on distance
- Calculate routes based on time
- Compare different route costs
- Visualize the selected path
- Load graph data from files
- Interactive JavaFX interface

## Algorithm

The application uses **Dijkstra's Shortest Path Algorithm** to determine the minimum-cost path between nodes in a weighted graph.

The graph is represented using adjacency lists.

## Data Structures

This project includes custom implementations of several data structures:

- Graph
- Adjacency List
- Min Heap / Priority Queue
- Linked List
- Array List

These structures are used to support graph traversal and shortest-path calculations.

## How It Works

1. Graph data is loaded from a file.
2. The user selects a source node.
3. The user selects a destination node.
4. The application runs Dijkstra's Algorithm.
5. The shortest route and its cost are calculated.
6. The resulting path is displayed visually in the JavaFX interface.
